# Reference Scout

Use references only when they materially improve the project. If the user already provided strong references, analyze them first.

Classify useful signals as:
- layout
- motion
- typography
- transition
- camera
- sound
- interaction
- material/texture

Extract pacing, hierarchy, shape language, palette behavior, camera grammar, transition grammar and interaction physics.

Prefer synthesis from 2–4 sources. Never copy a third party's logo, exact composition, copy, distinctive artwork or brand system.

Output:
- reference board
- transferable traits
- Style DNA signals
- motion-pattern candidates
- explicit DO / DON'T list
