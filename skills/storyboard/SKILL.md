# Storyboard

Every non-trivial multi-scene video gets a storyboard before full implementation.

For each scene define:
TIME
PURPOSE
VISUAL/COMPOSITION
COPY
MOTION
CAMERA
AUDIO
ENGINE CANDIDATE
PATTERN
ACCEPTANCE

Rules:
- one main focus per scene
- clear visual handoff between scenes
- keep copy on screen long enough to read
- prefer meaningful transitions over decorative cuts
- do not rescue a weak story with more effects
- make scene timings add up to project duration

Write approved scene data back into `motion/motion-project.json` when working in a code repo.
