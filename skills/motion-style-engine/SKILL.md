# Motion Style Engine

Run before storyboard unless a valid Style Lock already exists.

## Creative DNA
Extract:
- Product Truth
- Audience Desire
- Positioning / Values
- Reference Signals
- Visual Axes
- Central Mechanism
- Forbidden Cliches

Every style choice must trace to the brief, brand or explicit references.

## Visual axes
Use 0–100 routing values, not quality scores:
- Restrained → Expressive
- Geometric → Organic
- Familiar → Experimental

## One expressive move
Choose one dominant mechanism. Supporting typography, palette, texture and effects should stay quieter.

## Style Lock
Freeze:
- medium
- palette logic
- line/fill behavior
- texture/finish
- typography character
- camera grammar
- lighting grammar
- realism level
- expressive move
- anti-slop rules

## Style Key
May be an approved frame, style board, abstract swatch, user reference or saved profile. For generative shots, use the Style Key only as a style donor unless other reference roles are explicit.

## Reference roles
STYLE, IDENTITY, PRODUCT, COMPOSITION, FIRST_FRAME, LAST_FRAME.
Never silently treat one image as every role.

## Profiles
Read `references/style-library.md` and `references/style-profiles.json`.

## Output
Return a compact Style Lock object and the rationale in practical terms. If the user asks for options, propose three strategically different directions, not hue variations.
