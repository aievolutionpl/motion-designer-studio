# Studio defaults

Opinionated starting point for the studio's own projects.

Use only when the user did not give stronger project-specific direction.

## Visual defaults
- premium, minimalist, visual-first
- one main message per scene
- strong hierarchy and negative space
- bold readable typography
- cinematic but controlled lighting
- realistic/product-faithful assets when applicable
- motion should guide attention, not decorate

## Avoid
- generic AI stock look
- too many tiny icons
- random purple/cyan glow
- gratuitous glassmorphism
- random particle fields
- fake dashboards and fake microtext
- several competing effects in the same scene
- unnecessary slogans

## Formats
- 9:16 for reels/vertical ads
- 4:5 for social feed
- 16:9 for launch/cinematic/product presentations

## Working preference
Prefer a working build and preview over a long theoretical explanation. Keep the code modular enough to reuse successful patterns later.
